# DAIC — десктопний компаньйон «Ї»

Для Windows 11 x64: прозорий персонаж поверх звичайних вікон, перетягування, збереження позиції, один екземпляр і керування через трей. Після першого статичного етапу додано рідке моргання: випадкова пауза 4–8 секунд, один прохід 8 кадрів по 42 ms і повернення до neutral. При приховуванні таймер зупиняється. Без ШІ, мережевого сервера й автооновлення.

Main передає факт show/hide через вузький preload-міст; renderer може лише підписатися на boolean видимості. Доступу до файлів або команд головного процесу немає. Це потрібно, оскільки Page Visibility у перевіреному Electron-середовищі залишався `visible` після native hide.

## Запуск

Перевірене середовище: Node.js 24.20.0, npm 11.19.0, Windows 11 x64.

```powershell
npm.cmd ci
npm.cmd start
```

`start` автоматично компілює TypeScript і копіює незмінний PNG у `dist/`. Він запускає desktop Electron; оболонка запуску прибирає тільки з дочірнього процесу успадкований `ELECTRON_RUN_AS_NODE`, якщо його встановило середовище IDE.

Закривати програму через трей → **Вийти**. Приховування не завершує процес. Повторний запуск показує наявного персонажа без другого екземпляра.

## Налаштування

Файл `%APPDATA%\DAIC\settings.json` містить `{ "version": 1, "position": { "x": 100, "y": 120 } }`. Координати у DIP. Запис після 250 ms без руху та перед приховуванням/виходом; тимчасовий файл замінює попередній. Пошкоджені дані або недоступна позиція ведуть до стандартної позиції на основному моніторі. Помилка запису не блокує поточний сеанс; діагностика — `daic.log` поруч із settings.

Висота непрозорої частини персонажа — близько 128 DIP. Alpha-межі оригіналу обчислюються під час запуску; PNG не обрізається й не перезаписується. Невелике вікно має прозорий відступ 2 DIP.

## Перевірки

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:smoke
npm.cmd run check:artwork
```

Smoke запускає реальний Electron і окреме тестове вікно Chrome, якщо Chrome доступний. Перевіряє PNG, геометрію, відсутність focus, persistence між процесами, single-instance, callbacks трея та завершення процесів. Початковий `settings.json` відновлюється після діагностики. Запускайте smoke лише коли звичайний DAIC закритий. Докази — `.local/smoke-results.json` і `.local/daic-window.png`.

Smoke не є native mouse-drag тестом і не натискає меню трея фізично. Ручне приймання й фактичні обмеження описані у [звіті етапу](Tasks/daic_stage1_verification.md).

`check:artwork` перевіряє джерельні PNG/JSON без редагування. Якщо metadata не відповідає очікуванням, команда повертає exit code 1. Джерельний JSON має durations `[83,42,83,83,83,83,83,83]`, тому перевірка виявляє розбіжність. Для погодженої швидкості моргання збірка створює окремі runtime-дані з 42 ms на кадр (24 FPS з округленням), не змінюючи source-файли.

Перевірка реальних інтервалів і кадрів: `node scripts/smoke-blink.cjs`; для packaged exe: `node scripts/smoke-blink.cjs out/DAIC-win32-x64/DAIC.exe`. Деталі — [моргання](Tasks/daic_blink.md).

## Пакування

```powershell
npm.cmd run package
```

Forge створює Windows x64 папку застосунку в `out/`. Результат пакування потрібно перевіряти окремо. `npm.cmd run make` передбачено для майбутнього Squirrel-інсталятора; інсталятор і підписування не входять у приймання цього етапу.

Після зміни коду чи джерельного PNG завершити DAIC через трей й повторити `npm.cmd start`. Для наявної packaged-версії також повторити `npm.cmd run package`.
