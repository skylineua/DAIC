# DAIC — результат першого етапу реалізації

Дата: 28.10.2026. **Статус: реалізовано; автоматична перевірка реального Electron пройдена; повне ручне приймання ще не завершене.**

Перед роботою перевірено репозиторій: існували лише підготовчі документи та невідстежувані `source/` і `img/`; прикладного коду не було. Файлів `AGENTS.md` у репозиторії не знайдено; застосовано правила, надані користувачем у чаті.

Джерело правди, контракт і межі зафіксовані в [описі етапу](daic_stage1_scope.md). Технологічне спрощення щодо PREP-03 явне: tsc + копіювання ресурсів + Forge, без Webpack і dev server. Жодних анімацій або IPC не додано.

## Реалізовано

- SettingsService: JSON v1 у `%APPDATA%\DAIC`, перевірка типів/чисел, тимчасовий файл і rename; помилки не блокують сеанс.
- PositionService: координати DIP, від’ємні монітори, повне вміщення в workArea, fallback на основний екран із відступом 24 DIP.
- WindowService: прозоре вікно без рамки й тіні, alwaysOnTop, skipTaskbar, focusable:false і showInactive; повторна перевірка позиції на показі та зміні моніторів.
- Статичний renderer: штатна drag region, відсутність Node/preload/IPC, PNG без змін. Запис позиції після 250 ms без move та flush перед hide/quit. Таймер збереження не пересуває вікно посеред drag.
- TrayService: «Показати Ї»/«Приховати Ї», «Повернути на основний екран», «Вийти». Іконка формується в пам’яті з того самого PNG, вихідні файли не редагуються.
- Один екземпляр, показ прихованого персонажа при повторному запуску, завершення main/renderer/helper-процесів при виході.
- Команди запуску/перевірки/пакування, зафіксований package-lock, README.

## Графіка й анімаційні metadata

Статичний PNG: `512 × 512`, alpha bounds `x=150..362`, `y=100..479`, тобто `213 × 380 px`. Масштаб `128/380`; весь оригінальний PNG відображається з розміром близько `172.46 × 172.46` DIP зі зміщенням усередині viewport. Вікно `76 × 132` DIP включає прозорий відступ 2 DIP навколо видимої частини. Прозорі поля не обрізаються у файлі.

Аркуш blink: `4096 × 512`. Усі 8 прямокутників JSON мають розмір `512 × 512`, `y=0`, `x=0,512,...,3584`; вони не виходять за межі PNG й не перекриваються. `frameCount=8`, `fps=24`, `loop=false` відповідають очікуванню.

**Розбіжність:** фактичні durations — `[83,42,83,83,83,83,83,83]`, а не 42 для кожного кадру. Кадри з індексами 0 і 2–7 не відповідають вимозі. JSON залишено без редагування; `npm.cmd run check:artwork` закономірно повертає exit code 1 саме через ці durations. Анімація не підключена й не потрапляє в runtime-пакет.

Windows computer-use helper не зміг ініціалізуватися: `trusted Node process exited unexpectedly; kernel reset, rerun your request`. Повторення й reset не відновили роботу. Тому native mouse/tray/desktop-overlap перевірки не оголошуються виконаними. Реальний запуск і решта сценаріїв перевірені через Playwright Electron API, без підміни runtime mocks.

Початкове середовище Codex має `ELECTRON_RUN_AS_NODE=1`; launcher прибирає її лише для дочірнього GUI Electron. Системні змінні, політики Windows і параметри безпеки не змінювалися.

Докази локально: `.local/smoke-results.json`, `.local/daic-window.png`, `.local/smoke-results-packaged.json`, `.local/daic-window-packaged.png`. Smoke тимчасово перевіряє settings і повертає початковий вміст після тесту; вихідні зображення не чіпає. Діагностику запускати лише коли звичайний DAIC закритий.

## Ручне приймання користувачем

1. `npm.cmd start` або `out\DAIC-win32-x64\DAIC.exe`. Побачити одну «Ї» без рамки, прямокутного фону й кнопки на панелі задач.
2. По черзі розгорнути VS Code та браузер: персонаж залишається поверх них. Під час запуску персонажа введення в активному редакторі не перехоплюється.
3. Лівою кнопкою перетягнути персонажа, зробити коротку паузу, продовжити рух; перевірити відсутність стрибків. Перевірити drag разом із focusable:false.
4. Трей → «Вийти», потім повторний запуск: позиція відновлена.
5. Відкрити меню трея правою кнопкою: приховати, показати, повернути на основний екран. Повторити запуск під час hidden — один персонаж показується.
6. «Вийти»: іконка й персонаж зникають, процеси завершуються.
7. За можливості перевірити краї на світлому/темному тлі, DPI 100/125/150% і від’єднання додаткового монітора.

Перезбірка для отриманого коду вже виконана. Після змін коду/PNG завершити запущений DAIC і знову `npm.cmd start` (перезбирає автоматично). Для packaged exe повторити `npm.cmd run package`.

Поточний етап не позначається повністю прийнятим до виконання ручних сценаріїв вище. Інсталятор і всі функції за межами цього запиту не вважаються завершеними.
